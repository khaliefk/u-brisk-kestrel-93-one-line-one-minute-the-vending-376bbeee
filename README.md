One pickup line, 200 characters at most, as if a vending machine were flirting with a passing human. `main.py` writes that line to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

To test locally without `/output`, point it elsewhere:

```sh
OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
